## Toutiao Hot News API Discovery
- **API Endpoint**: `https://www.toutiao.com/hot-event/hot-board/?origin=toutiao_pc`
- **Method**: `web_fetch` with extractMode=json works perfectly
- **Data Structure**: JSON with `data[]` array containing:
  - `Title`: News headline
  - `HotValue`: Heat score (integer as string)
  - `Label`: Tags like "hot", "new", "onSite"
  - `ClusterIdStr`: Unique ID
  - `Image`: Image object with URL
  - `InterestCategory`: Category tags (sports, finance, etc.)

## Browser Navigation Note
- When using `browser navigate`, be careful with target URL - initially loaded 36kr.com instead of toutiao.com
- Always verify the loaded URL matches intent

## Tool Limitations
- `web_search`: Requires Brave Search API key (configured via `openclaw configure --section web`)
- `web_fetch` on dynamic sites like toutiao.com returns minimal content
- API endpoint approach is more reliable than scraping for hot news
